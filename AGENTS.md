# Shared Class Project Instructions

Multiple students develop this application through separate Codex chats connected to the same shared GitHub repository.

1. Before making changes, retrieve the latest version of the repository. Inspect the working tree, fetch the latest remote changes, and incorporate them safely while preserving any local work.
2. Preserve all existing application functionality.
3. Do not overwrite or discard another student's work.
4. After completing a task, test the changes and commit them with a descriptive commit message.
5. Push completed changes to the shared GitHub repository.
6. Immediately before pushing, check whether other students have pushed new changes. If so, incorporate those changes safely and rerun relevant tests before pushing. If the push is rejected because the remote advanced, repeat this check and integration process.
7. If conflicting changes cannot be safely combined, stop and explain the conflict rather than overwriting anyone's work.
8. Never force-push to the shared repository.
